## もっと使いこなすための3つのコツ

### コツ1：「口調」を指定する

プロンプトに「丁寧なビジネス敬語で」や「箇条書き中心で簡潔に」と加えるだけで、出力スタイルが変わります。社内向けと社外向けで使い分けると便利です。

### コツ2：「要約の長さ」を指定する

「全体を500文字以内にまとめて」と指定すると、上司への報告用に短くまとめた版も作れます。

### コツ3：音声文字起こしと組み合わせる

ZoomやGoogle Meetの文字起こし機能、またはiPhoneのボイスメモを使えば、会議の音声をテキスト化できます。そのテキストをそのままChatGPTに貼り付けると、さらに精度の高い議事録が作れます。

## よくある失敗パターンと対処法

### 失敗①：「情報が少なすぎる」と言われる

**原因：** メモが少なすぎてChatGPTが補完できない  
**対処法：** プロンプトの最後に「不足している情報は『〇〇（要確認）』と明記してください」と追加する

```
※情報が不足している箇所は「（要確認）」と記載してください。
```

---

### 失敗②：出力がいつもバラバラで統一感がない

**原因：** 毎回プロンプトを書き直している  
**対処法：** テンプレートをNotionやGoogleドキュメントに保存しておき、毎回コピペする習慣をつける

---

### 失敗③：担当者名が間違って記載される

**原因：** メモの書き方が曖昧（「田中→確認」だと誰が確認するのか不明）  
**対処法：** メモの段階で「田中さんが確認する」「山田さんへ依頼」のように主語を明確にする

---

### 失敗④：機密情報をそのまま入力してしまう

**原因：** 顧客名・個人情報・未公開の数字をそのまま入力  
**対処法：** 入力前に以下のように置き換える

| 実際の情報 | 置き換え例 |
|-----------|------------|
| 株式会社〇〇（クライアント名） | クライアントA社 |
| 山田太郎（個人名） | Aさん |
| 売上1億2000万円 | 売上X円 |

## ボーナス：Googleドキュメントと連携して全自動化する方法

さらに効率を上げたい方向けに、**Googleドキュメント × ChatGPT API**を使った半自動化の考え方をご紹介します。

1. **会議メモをGoogleドキュメントに入力**
2. **Google Apps Script（GAS）でChatGPT APIを呼び出す**
3. **議事録が自動生成されて別のドキュメントに保存される**

GASのコードのひな型はこちらです（OpenAI APIキーが必要です）：

```javascript
function createMinutes() {
  const doc = DocumentApp.getActiveDocument();
  const memo = doc.getBody().getText();

  const apiKey = 'YOUR_API_KEY'; // ここにAPIキーを入れる
  const endpoint = 'https://api.openai.com/v1/chat/completions';

  const prompt = `以下の会議メモをもとに、ビジネス用の議事録を作成してください。
決定事項・議論内容・次のアクション（担当者・期限つき）の形式で。

【会議メモ】
${memo}`;

  const payload = {
    model: 'gpt-4o',
    messages: [{ role: 'user', content: prompt }],
    temperature: 0.3
  };

  const options = {
    method: 'post',
    contentType: 'application/json',
    headers: { Authorization: `Bearer ${apiKey}` },
    payload: JSON.stringify(payload)
  };

  const response = UrlFetchApp.fetch(endpoint, options);
  const result = JSON.parse(response.getContentText());
  const minutes = result.choices[0].message.content;

  // 新しいドキュメントに議事録を保存
  const newDoc = DocumentApp.create('議事録_' + new Date().toLocaleDateString('ja-JP'));
  newDoc.getBody().setText(minutes);

  Logger.log('議事録を作成しました: ' + newDoc.getUrl());
}
```

このスクリプトを使えば、**メモを書いてボタンを押すだけで議事録ドキュメントが自動生成**されます。
