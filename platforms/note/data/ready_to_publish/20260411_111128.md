# ChatGPTで副業アイデアを100個出す方法｜初心者が最初にやるべきプロンプト設計の基本

タグ: #ChatGPT活用, #副業, #生成AI, #プロンプト

---

「副業を始めたいけど、何から手をつければいいか分からない」という声はよく聞かれる。そんな時に役立つのがChatGPTを使ったアイデア出しだ。今回は、初心者でもすぐ真似できるプロンプト設計の基本と、そのまま使えるテンプレートを整理する。

## なぜChatGPTで副業アイデアを出すのか

一般的に、副業で成果を出す人は「自分のスキル」と「市場のニーズ」が重なる領域を選んでいると言われている。しかし初心者がこの掛け算を一人で考えるのは難しい。ChatGPTは大量のパターンから候補を提示できるため、発想の壁打ち役として向いている。

ただし注意点がある。ChatGPTは「平均的で当たり障りのない回答」を返しがちだ。ざっくり「副業のアイデアを教えて」と聞くと、ブログ・せどり・Webライターといった誰でも知っている答えしか返ってこない。ここで効いてくるのがプロンプト設計だ。

## 質の高いアイデアを引き出す4つの要素

プロンプトに以下の4要素を入れると、回答の解像度が上がると言われている。

- 前提条件 → あなたのスキル・使える時間・資金
- 制約条件 → 初期費用ゼロ、在宅のみ、など
- 出力形式 → 箇条書き、表形式、ステップ形式
- 役割設定 → 「副業コンサルタントとして」など

この4つを意識するだけで、抽象的な回答から一歩踏み込んだ提案に変わる。

## そのまま使えるプロンプトテンプレート

以下は初心者が最初に試せる基本形だ。コピーして【】内を書き換えるだけで使える。

```
あなたは副業コンサルタントです。
以下の条件に合う副業アイデアを20個提案してください。

【私の状況】
- 本業: 【例: 事務職】
- 使える時間: 平日1時間・休日3時間
- 初期費用: 【例: 1万円以内】
- 得意なこと: 【例: 文章を書くこと】
- 避けたいこと: 【例: 顔出し・在庫を持つ】

【出力形式】
1. アイデア名
2. 月収の目安（一般論で可）
3. 必要なスキル
4. 始め方の最初のステップ

ありきたりな提案は避け、ニッチで具体的なものを優先してください。
```

このテンプレートのポイントは最後の一文だ。「ありきたりを避ける」「ニッチを優先」と明示することで、平均的な回答から外れた候補が出やすくなる。

## 100個出すための追加プロンプト

20個の回答が返ってきたら、次はこう続ける。

```
上記とは全く違う切り口で、さらに20個提案してください。
特に【AIツール活用】【地方在住者向け】【40代以降向け】など
視点を変えた候補を含めてください。
```

「切り口を変える」と指示するのがコツだ。これを5回繰り返せば100個のリストが手に入る。そこから自分に合うものを3〜5個に絞り込み、深掘りの質問へ進むのが王道の流れとされている。

## アイデアを絞り込むチェックリスト

出てきたアイデアを評価する時は、以下の観点で確認すると選びやすい。

- 実現性 → 今のスキルで3ヶ月以内に着手できるか
- 継続性 → 飽きずに続けられそうか
- 収益性 → 時間単価が最低賃金を下回らないか
- 拡張性 → 将来スキルや資産として積み上がるか
- 適合性 → 自分の生活リズムに合うか

この5項目を5段階で採点し、合計点が高いものから検討するのが一つの方法だ。

## よくある失敗パターン

注意したいのは「ChatGPTの回答を鵜呑みにする」こと。AIは最新の市場動向や規約変更を完全には把握していない。提案されたアイデアは必ず自分で一次情報を調べ直す前提で使うのが安全だと言われている。また、収益の目安として出てくる金額も参考値に過ぎないため、過度な期待は禁物だ。

## まとめ

ChatGPTは副業アイデアの「発散」に圧倒的に強い。一方で「絞り込み」や「検証」は人間側の仕事になる。今回紹介したテンプレートとチェックリストを組み合わせれば、迷いがちな最初の一歩を効率化できるはずだ。まずは一度、自分の条件を入れてプロンプトを回してみてほしい。
