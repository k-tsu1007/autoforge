## 記事タイプ: 技術比較系

「ツール・ライブラリ・フレームワーク・サービスのどれを選ぶか迷っている」読者向け。
CV率が最も高い記事タイプ。技術選定の文脈で比較する。

**主語のルール（絶対厳守）**
- 「副業」を主語にしない。「技術選定」「学習効率」「実装場面」を主語にする。
- 例: 「副業で使うなら〇〇 vs △△」→ NG / 「API連携を実装するなら〇〇 vs △△、選ぶ基準を整理した」→ OK

## note (uta_lab_) 連動ルール

uta_lab_ の note 記事で取り上げた技術テーマと連動する場合、以下の役割で書く:
- note が「設計思想・実装詳細」を担うなら、このブログは「初心者が選ぶ基準を整理する比較記事」を担う。
- 連動例: note「エージェントフレームワーク選び」→ アフィ「LangChain vs LlamaIndex、用途別にどちらを選ぶか整理した」
- 連動例: note「Claudeのサブエージェント実例」→ アフィ「Claude API vs OpenAI API、マルチエージェント実装での比較」

## 構成
- 冒頭: 「AとB、どちらを選ぶべきか」と読者の技術選定の迷いに共感
- H2構成: 「比較の前提 (選ぶ基準)」→「各技術・ツールの特徴」→「用途・場面別おすすめ」→「結論・CTA」
- 比較軸を明確にして読者が自分の用途に合う方を選べるようにする
- 長所だけでなく短所も正直に書く
- 「この用途ならXがおすすめ」と明言してからCTAへ誘導

## E-E-A-T (検索評価) を意識
- ケンタの等身大視点:「実際に両方試した」「実装してみて気づいた差」
- 具体的な操作・コード感覚・体感の違いを書く
- 根拠のない断言は避け「〜という場面では使いやすい」「〜の用途には向かないとされている」で表現

## アフィリエイトCTA（技術習得・効率化文脈で使う）
- スクール系 → 「どちらも体系的に学ぶなら」という文脈でWinスクール無料カウンセリングへ誘導
- WordPress/サーバー系 → 「実際に動かす環境を用意するなら」という文脈でエックスサーバーへ誘導
- AIツール系 → 「比較した技術を手軽に試せるサービスなら」という文脈でConoHa AI Canvas等へ誘導
- CTAは「広告」「PR」と明示 (絶対厳守)

## タイトル多様性ルール（厳守）

### 禁止テーマパターン（過去記事と被らせない）
過去記事一覧が別途提示される。その一覧を必ず確認し、以下を守ること:
- 「AI画像生成で副業」というフレーズを含むタイトルは作らない（既出多数）
- 「AIブログアフィリエイト」というフレーズを含むタイトルは作らない（既出多数）
- 「副業」を主語・前面に出したタイトルは作らない（技術選定が主語であること）
- 「ChatGPT vs Claude」「Gemini vs Claude」などのAIモデル対決は直近10記事内で1本まで
- 過去記事と同じ比較対象の組み合わせは繰り返さない

### 禁止語尾パターン（連続3本以内に同じものを使わない）
- 「〜どっちか」「〜どちらか」
- 「〜答え」「〜結論」
- 「〜出た答え」「〜試して出た結論」
- 「〜比べた」「〜書き比べた」
- 「〜選び方の結論」「〜選んだ理由」

### 比較対象の多様化ルール
比較記事が続く場合、以下のいずれかを変えること:
- 比較する**カテゴリ**（AIモデル比較ばかり避ける → フレームワーク比較・ライブラリ比較・クラウドサービス比較に変える）
- 比較の**用途軸**（AI生成軸ばかり避ける → 推論速度軸・コスト軸・学習コスト軸に変える）
- 比較の**主語**（ツール同士の比較 vs アーキテクチャ・設計方針の比較）

### 記事切り口9種のローテーション（必ず現在未使用の切り口を選ぶ）
1. How-to型: 「〇〇を選ぶときのチェックリスト」
2. Why型: 「なぜ今〇〇ではなく〇〇が選ばれているのか」
3. 比較型: 「AとB、〇〇の場面ならどちらを選ぶか整理した」
4. 解説型: 「AとBの違いがよくわからなかったので整理した」
5. 誤解解消型: 「〇〇は〇〇より難しいは本当か」
6. 提案ツール型: 「〇〇の用途に向いているライブラリを3つ試して絞り込んだ」
7. リスト型: 「〇〇を選ぶ前に知っておくべき比較ポイント〇つ」
8. 物語型: 「AからBに乗り換えた理由と、乗り換えて3週間の変化」
9. 疑問型: 「〇〇って結局〇〇と何が違うのか」

比較タイプは切り口3番が基本だが、誤解解消・解説・疑問型と組み合わせることで変化をつける。

### タイトル生成時の確認手順
1. 候補タイトルを3案考える（比較対象・軸・語尾がすべて異なるもの）
2. 過去記事一覧と照合し、比較対象・語尾・テーマが被っていないか確認
3. 「副業」が主語になっていないか確認
4. 最も新鮮な切り口の1案を選ぶ

### タイトル形式
- 30文字以内、SEOキーワード（技術名・ツール名）を含む
- 技術選定・実装用途が主語になっている
- NG: 「副業に使うAIツール、ChatGPTとClaudeどっちがいいか」（副業が主語）
- NG: 「AIブログアフィリエイト、量産か品質か試して出た答え」（禁止フレーズ）
- OK: 「LangChain vs LlamaIndex、RAG実装で選ぶ基準を整理した」
- OK: 「Claude API vs OpenAI API、2026年のコストと性能の差」
- OK: 「Vercel vs Netlify、個人プロジェクトのデプロイで使い比べた」
- OK: 「Cursor vs GitHub Copilot、コードエディタ統合AIの実力差」

- 捏造・架空の実績・数値主張は絶対禁止
- 文字数は別途指定される (それに従う)
