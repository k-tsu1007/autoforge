AIや開発ツールの最新ニュースを「で、これは何を変えるのか？」という視点で解説する記事を1本生成してください。

## 記事タイプ: 最新技術ニュース系

「AI / Claude / 新ツール / アップデートの情報をキャッチアップしたい」読者向け。SNS拡散・検索流入を狙う。
技術好き・エンジニア志望・学習中の社会人にも届く内容にする。

**主語のルール（絶対厳守）**
- 「副業」を主語にしない。「技術・ツール」が何を変えるか、何に使えるかを主軸にする。
- 例: 「副業に使えるか？」→ NG切り口 / 「エンジニア以外でも使える場面はあるか？」→ OK切り口
- 「お金になるか」「稼げるか」という問いかけは使わない。「仕事・学習・制作がどう変わるか」を問う。

## note (uta_lab_) 連動ルール

uta_lab_ の note 記事で取り上げた技術テーマと連動する場合、以下の役割で書く:
- note が「実装詳細・設計思想」を担うなら、このブログは「そのニュースが何を意味するかの解説」を担う。
- 記事内で note の関連記事に自然な形で言及してもよい（「この技術の実装例はnoteで詳しく書きました」等）。
- 連動例: note「Claudeのサブエージェント実装」→ アフィ「Anthropicが発表したマルチエージェント機能、何が変わるのか整理した」

## 構成
- 冒頭: 「〇〇がリリース/アップデートされました」と結論から入る
- H2構成: 「何が変わったか」→「技術的に何が新しいのか（背景・仕組み）」→「どんな場面で使えるか」→「まとめ」
- ケンタの視点で「エンジニア以外の人間として使えるか？」を評価する
- 速報感を出しつつ「で、これは何を変えるのか？」を必ず答える

## タイトル多様性ルール（厳守）

### 禁止テーマパターン（過去記事と被らせない）
過去記事一覧が別途提示される。その一覧を必ず確認し、以下を守ること:
- 「AI画像生成で副業」の切り口は作らない（禁止フレーズ）
- 「AIブログアフィリエイト」の切り口は作らない（禁止フレーズ）
- 「副業」を主語・前面に出したタイトルは作らない（技術が主語であること）
- 取り上げるAIツールが連続しないようにする（同じツール名を連続して使わない）
- 直近3本のnews記事のテーマ（AIモデル更新 / 画像生成 / 開発ツール）が重なる場合は別テーマを選ぶ

### 禁止語尾パターン（連続3本以内に同じものを使わない）
newsタイプで特に多発するため厳守すること:
- 「〜な件」（直近5本に2本以上あれば使用禁止）
- 「〜がすごい」
- 「〜に激震」「〜の衝撃」「〜を変えそうな件」
- 「〜追い風か」「〜変えるか」
- 「〜注目されている」「〜潮目が変わってきた件」

### ニュースの切り口多様化ルール
速報・ニュース解説でも切り口を変えること:
- 機能解説だけでなく「技術的に何が新しいのか」「業界への影響」を主軸にする
- 「ツール名＋機能」だけでなく「業界・エコシステムへの影響」視点も使う
- 懐疑・冷静評価の視点もOK:「〇〇は思ったほど革新的ではなかった」「〇〇の限界をちゃんと書く」

### 記事切り口9種のローテーション（必ず現在未使用の切り口を選ぶ）
newsタイプであっても切り口は多様にすること:
1. How-to型: 「新機能〇〇の使い方、実際にやってみた」
2. Why型: 「なぜ今〇〇がリリースされたのか、技術背景を読む」
3. 比較型: 「〇〇アップデート前後で何が変わったか」
4. 解説型: 「〇〇が話題だけど、実際どういう技術なのか整理した」
5. 誤解解消型: 「〇〇は本当に〇〇を変えるのか、誇張なしで評価した」
6. 提案ツール型: 「〇〇の登場で乗り換えを検討すべきサービスはこれ」
7. リスト型: 「〇〇で変わる3つのこと、技術者以外の目線でまとめた」
8. 物語型: 「〇〇リリース初日に試した、率直な1時間の記録」
9. 疑問型: 「〇〇って結局エンジニア以外には関係あるのか？試して考えた」

過去記事一覧の傾向を見て、最もカバーされていない切り口を選ぶこと。

### タイトル生成時の確認手順
1. 候補タイトルを3案考える（語尾・ツール名・視点がすべて異なるもの）
2. 過去記事一覧と照合し、語尾・ツール名・テーマが被っていないか確認
3. 「副業」が主語になっていないか確認
4. 最も新鮮な切り口の1案を選ぶ

### タイトル形式
- 具体的なツール名・機能名・技術名を含める（SNSシェアされやすい）
- 技術が主語になっている
- NG: 「AI最新ニュースまとめ」（汎用すぎ）
- NG: 「GPT-5.5発表、副業への追い風か」（副業が主語・禁止語尾）
- OK: 「Claude 4のリリースで何が変わるのか、技術的な差分を整理した」
- OK: 「Gemini 2.5 Pro、仕事でClaude使ってる自分が乗り換えを考えた理由」
- OK: 「OpenAI o3、推論モデルの仕組みと実用限界を整理した」
- OK: 「Perplexity Pro、検索エンジンとの根本的な違いを使って確かめた」
